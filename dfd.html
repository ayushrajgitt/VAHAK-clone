Data Stores
SQLite Database — Table Descriptions
D1 · Users Table
Stores user details, role, email, password hash, profile picture, and bio. One role per email enforced.
D2 · Loads Table
Stores load details, pickup, destination, price, status, OTP, and accepted driver/transporter references.
D3 · Transporter Drivers Table
Stores which drivers belong to which transporter. Used during acceptance and assignment (P3).
D4 · Notifications Table
Stores system updates for all users and the admin. Generated by load, delivery, payment, and support events.
D5 · Reviews Table
Stores ratings and written comments after completed shipments. Linked to user profiles.
D6 · Support Tickets Table
Stores customer questions submitted by Shippers, Drivers, and Transporters, along with Admin responses.
